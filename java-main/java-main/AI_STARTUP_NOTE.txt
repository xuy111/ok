【每次启动步骤（照做即可，不要过度分析）】
  1) 确认 MySQL 服务在运行（看 mysqld.exe，或 netstat -ano | findstr 3306）。
  2) 若数据库被重置过，先运行 init-db.bat 建库建表
     （springboot_test + user 表，账号 root/123456，幂等可重复执行）。
  3) 双击 start.bat（或命令行 call start.bat）：
       - 后端：开新窗口跑 mvnw spring-boot:run（target 已删，会重新编译）
       - 前端：开新窗口跑 npm install（重建 node_modules）+ npm run dev -- --port 5173
  4) 验证：浏览器开 http://127.0.0.1:8081 和 http://127.0.0.1:5173
  5) 停止：双击 stop.bat（按端口 8081/5173 杀进程）；重启：restart.bat

【已知坑 / 已修复】
  - 项目原本缺 .mvn/wrapper/maven-wrapper.properties，导致 mvnw.cmd 无法启动；
    已补回（distributionUrl 指向 Maven 3.9.9，首次会下载并缓存到 ~/.m2）。
  - node_modules、target 每次开机会被删：脚本已在运行时重建，启动前不要依赖它们。
  - 脚本均为 GBK 编码、相对路径；唯一绝对路径是 init-db.bat 里的 mysql.exe（系统路径）。
  - 后端默认走 dev profile（application-dev.properties），连 127.0.0.1:3306/springboot_test。
